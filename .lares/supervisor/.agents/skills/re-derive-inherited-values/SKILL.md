---
name: re-derive-inherited-values
description: >-
  A handoff prompt or predecessor's notes hand you a precomputed value — a hash, version number, line count, or ID — to use in a load-bearing edit.
---
Re-derive it yourself before use; never paste it in on trust. Before trusting your OWN derivation, calibrate the pipeline by reproducing a value that is already recorded and known-good (e.g. hash an older fixture and match its shipped constant). If your pipeline reproduces the known value but not the inherited one, the inherited value is wrong — say so and use yours.
