# PDF fixtures (dual-viewer trunk, plan Part 1.12)

Small, valid PDFs that exercise the hard cases for the dual-system PDF viewer's
**engine-independent trunk** — the paint-disabled text model, the anchor
capture/reattach ladder, and the overlay projection math. They are the R3
alignment guardrail (rotated crop boxes, ligatures, mixed sizes) and the R5
scanned-page case (coordinate-only notes).

All files are generated by [`generate.mjs`](./generate.mjs) — raw PDF assembly,
no dependencies — and **committed** so tests need no generation step:

```
node examples/pdf-fixtures/generate.mjs
```

Re-run only when a fixture must change; the generator recomputes xref offsets, so
edits stay valid.

## The fixtures

| File | Exercises | Key properties (verified via pdf.js) |
|---|---|---|
| `selectable-text.pdf` | baseline text extraction + anchor prefix/suffix context | 1 page, `/Rotate 0`, multi-line Helvetica text |
| `rotated.pdf` | rotated crop box → projection applies `/Rotate` only at paint time | 1 page, `/Rotate 90` |
| `mixed-size.pdf` | per-page crop-box dims; slot height reservation | 2 pages, `612×792` then `1008×612` |
| `ligature.pdf` | ligature stays ONE selectable unit | `fi`/`fl` via `/Encoding /Differences`; pdf.js extracts them as `fi`/`fl` |
| `image-only.pdf` | scanned/image page → **coordinate-only** notes (no extractable text) | 1 page, image XObject, `getTextContent()` empty |
| `link-annotation.pdf` | link-annotation handling + navigation policy | 1 page, one `/Link` annot with an external `/URI` |

## Referenced, NOT committed

Per the plan, some inputs are referenced rather than committed for size/licensing
reasons — obtain them locally when needed:

- **Dense-vector benchmark** — `s41467-021-24192-8.pdf` (page 3 ≈ 1.47 M path
  points), the pathological page that motivates PDFium and gates Phase 0. Do not
  commit; place it alongside these fixtures locally for the raster benchmark.
- **Full RTL / CJK sample** — true right-to-left or CJK text needs an embedded
  font with those glyphs, which the base-14 fonts used here cannot express, so
  `ligature.pdf` locks only the ligature-as-one-unit case. For end-to-end RTL
  alignment testing, source a real embedded-font Arabic/Hebrew PDF locally rather
  than committing one.
