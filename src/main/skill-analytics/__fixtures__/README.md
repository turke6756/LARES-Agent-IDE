# WP2 parse fixtures — real corpus lines (P0.1)

Every `.jsonl` here is derived from **real** entries in `~/.claude/projects`
(read-only source), trimmed of cache/diagnostics noise (`cache_creation` object,
`server_tool_use`, `iterations`, `requestId`, `diagnostics`) while preserving every
field the detectors read: top-level `uuid` / `type` / `cwd` / `sessionId`, and
`message.{role,model,content,stop_reason,usage}` where present. The four canonical
usage fields (`input_tokens`, `cache_creation_input_tokens`,
`cache_read_input_tokens`, `output_tokens`) are kept verbatim. Composed streams
re-link `uuid`/`parentUuid`/`sessionId` into one coherent stream; payload block
shapes stay real. Regenerated by `scratchpad/gen-fixtures.js` (not shipped — the
`.jsonl` files are the durable artifact).

## Confirmed on-disk shapes (verified in-tree)

- Entry carries top-level `uuid`, `cwd`, `sessionId`, `timestamp`, `type`,
  `message`. Assistant `message` has `model`, `content[]`, `stop_reason`, `usage`.
- `usage` is four **disjoint** fields; the live gauge sums all four
  (`claude-jsonl-reader.ts:643-647`) → `input_tokens` already excludes cache-read.
- A `Skill` invocation is `assistant` `content[i]={type:'tool_use', name:'Skill',
  input:{skill,args}}` with `stop_reason:'tool_use'`.
- `tool_result` blocks (incl. `is_error:true`) live inside `type:'user'` entries.
- Subagent streams live under `**/subagents/agent-*.jsonl`; entries carry
  `isSidechain:true` + `agentId` (the `agent-*` stem).
- Slash commands appear in `user` entries as
  `<command-name>/X</command-name>\n<command-message>…</command-message>\n<command-args>…</command-args>`.
- Non-user/assistant/system entry `type`s exist and MUST be skipped:
  `attachment`, `last-prompt`, `ai-title`, `mode`, `permission-mode`,
  `file-history-snapshot`.
